## Why changing only the product byte is insufficient

The envelope and much of the Gen-3 editor transport are shared. Parameter
addresses and SET value domains still need device-specific evidence. The
pinned upstream Axe-Fx III inventory contains 2,216 named records, 2,186 unique
family/parameter addresses and 30 duplicate addresses (old/new Flanger entries).
492 named records have different parameter IDs from TC's FM9 catalog.

`tools/afx3_catalog_audit.py` joins that inventory with the locally installed
32p6 cache for the known sections and TC's actual runtime allowlist. It never
opens MIDI, infers SET encodings from ranges, imports ambiguous addresses into
the writer, or exposes private name tables. The download is opt-in, pinned to
commit and SHA-256. It does not turn 2,216 named records into 2,216 supported
writes. The current runtime surface has **39 scalar/enum controls**, in
addition to the separately supported model, cab selection, routing, scene,
name and modifier actions.

Primary data source, Apache-2.0:
[device-specific catalog](https://github.com/TheAndrewStaker/mcp-midi-control/blob/59047175cfc4f23e092931b54a7c54f2bffde3ea/packages/fractal-midi/catalog/axe-fx-iii.json).
See `THIRD_PARTY_NOTICES.md` for attribution. Its upstream display metadata is
not adopted as a blanket write calibration.

## New supported Cab Legacy controls

FW 32.06 only, Cab 1-4, current channel A-D, Legacy mode only:

| TC parameter | Parameter IDs | Display values | Captured SET float (`01 09`) |
|---|---|---|---|
| `CABINET_LEVEL1..4` | 8-11 | -40..0 dB | literal dB, including zero |
| `CABINET_PAN1..4` | 12-15 | -100..100 | signed fraction, including zero |
| `CABINET_MUTE1..4` | 24-27 | 0 normal, 1 mute, 2 solo | integer ordinal, including zero |

Each write checks the device/firmware/spec, active channel, 424-word layout,
Legacy type, all four modes and independent display values. A full-block
comparison checks that other words/channels were not changed. Dyna-Cab,
unknown readings, fractional mode values, changed channels and out-of-range
values fail closed. Raw undo uses the verified bulk law and requires exact
word equality, not a cab-selection or enum fallback.

`set_cab` remains selection-only. The planner now has explicit, reviewable
actions for participating IRs, levels and pan; nothing silently unmutes an IR.
Solo exclusion considers all four slots. Two correlated IRs can raise output;
the prompt advises conservative per-IR levels for a new blend. This is not a
limiter or loudness measurement. Mixer actions require the same external-mute,
target and routing checks in the server and the UI, including manual edits.

- 56 captured-frame checks with independent display/full-block reads.

## Wah zero fix

Axe-Edit's typed `01 09` zero is a real SET for `WAH_INDUCTOR_BIAS`,
`WAH_QTRACKING` and `WAH_FAT` on FW 32.06. It must not be confused with a safe
generic GET. The old GET-shaped helper is not used for AFX3 passive reads.

Captured 5 -> 0 -> 5 through Axe-Edit, then independently verified 0 -> 5 for
all three fields by direct captured frames and again via TC's validator and
production executor. Full-block comparison proved exact restoration and no
collateral parameter change. The profile now advertises these exact-zero
capabilities; no epsilon substitution or guessed alternate opcode is used.
Missing capability or unsupported firmware still refuses before a build.

Evidence: `20260919-104500-wah-zero.jsonl` under the capture directory and
`backups/afx3-wah-zero-*.jsonl`. This supersedes the earlier zero-write limit
recorded in `AFX3-ZERO-PREFLIGHT-2026-09-18.md` for these three fields only.

## Combined hardware acceptance

`tools/afx3_four_scene_check.py` ran **113 actions** through `_apply_for`, the
same guarded executor used by SEND, with the complete serial route:

Input 1 -> Wah 1 -> Amp 1 -> Cab 1 -> Delay 1 -> Reverb 1 -> Output 1.

- Amp A-D: Brit 800 2204 High, gains 1/3/5/7, mids 3/4/5/6; level -30 dB.
- Output level -30 dB; external mute remained required throughout.
- IR 1/2 both normal, -6 dB, pan -100/+100; IR 3/4 muted.
- Delay A/B: 280/380 ms, 18/24% feedback, 15/18% mix; final level 0 dB.
- Reverb A: Small Room, 1.2 s, 8%, final level 0 dB.
- Cry Babe, three exact-zero controls, final level 0 dB, External 1 binding.
- Wah/delay engaged in scenes 1/4, bypassed in scenes 2/3.

All actions and the final route check passed. Revisiting all four scenes
independently confirmed distinct amp channels/values, delay times, cab mix and
bypasses. Exactly one External 1 -> Wah Control binding was found; global
pedal/CC mapping was not changed. Axe-Edit then independently displayed the
same A-D gain/mid values, scene labels, both IRs active and the cab level/pan
settings. Screenshots and structured evidence are under `backups/`.

This was an execution test, not a musical preset or an acoustic tone match.
Physical pedal sweep, speakers/headphones, audible balance and the reference
recording were not measured. Broad DSP parity with the FM9 is not claimed;
unsupported parameters remain a separate evidence-driven expansion task.

# Captured Pitch placement primitive

This is reusable **developer preparation**, not activation of the normal
text/scene preset builder. The existing Pitch octave-pedal tool configures
an already present block; this separate primitive prepares that block for a
future integrated construction workflow. It is not a second GUI or installer.

## Exact measured scope

Only the previously captured cursor and insertion frames for Pitch1 at
row1/column2 are admitted. The insert frame's opaque argument is retained;
it is not relabeled as a proven coordinate formula. Other positions,
Pitch2, moves, shunts, cables, deletion and preset replacement remain refused.

The current fixture must be disposable preset327, scene1, exact MK2
`33.00-beta5.20261026` full identity, in the measured native environment.
It contains only a Bassguy Amp1/A at row1/column1, independently displayed
Level at most -12dB, and no I/O/cables. All32 modifiers must be inactive and
unassigned. Declared MK1, other firmware and ordinary application mode refuse
the component. It never opens a connection or changes a global CC mapping.

An already present Pitch1/A at the exact destination is independently
verified and treated as a no-op, never deleted and recreated. The primitive
does not select a Pitch model or configure its parameters, mixer, controller
or Auto Engage. Those remain separate operations and acceptance scopes.

## Review and preservation contract

The host explicitly composes `Writer` with its current adapter, actual
device-switch/Gig Lock lock and selection/Gig callbacks, and an explicit
calibration opt-in. Call its methods outside an already held non-reentrant
host lock. An explicit `Request(327)` is required; there is no executor
fallback, new API route or normal AI action.

Preparation performs repeated complete reads and creates an opaque,
connection-owned sixty-second review. Apply consumes it before checking
target/mute booleans, context, expiry and the full state fingerprint.
The final output has exact captured bytes, one-use thread-owned permission,
and a fresh deadline/context check before each of the two commands.

Before insertion, status, grid, identity, Amp/controller block data, all32
modifiers, eight scene names and independent Amp level must be coherent.
After the cursor command the baseline is checked again. After insertion
only the new Pitch block/status/cell may differ. Every preexisting word,
modifier, name, channel, level and cell must remain unchanged. Native 65535
sentinels in opaque data are preserved, not normalized or used as setters.
Settling retries are reads only, never repeated commands.

Firmware queries ignore unrelated, checksum-valid editor acknowledgements,
including the captured cursor echo. A function8 response is still checked
against the complete measured fingerprint. Unknown builds are rejected;
the parser does not substitute a known identity or repeat a cursor command.

An unknown outcome or interruption after a command latches the shared Pitch
connection uncertain and prevents further Pitch work. No automatic repair,
rollback, deletion, reload or Store is offered. External mute is an explicit
user condition, not something TC can measure or enforce. The disconnected
fixture is not a playable sound or a physical-volume guarantee.

## Acceptance boundary

The earlier private measurement established one exact placement/removal
position on the owner's MK2 and an independent Axe-Edit comparison. It is
not acceptance of this newly extracted component. Scripted-context tests
cover bytes, replay, stale state, unsupported scope, concurrency, expiry,
interruptions and full preservation. Native/readback and fresh Axe-Edit
acceptance of this final source are recorded separately before treating it
as an accepted building primitive. Ordinary text-driven chain construction
and Pitch Auto Engage still require additional integration and verification.

On2026-10-28 the extracted component inserted Pitch1/A using exactly one
cursor and one insertion command. Complete native readback preserved all
preexisting state, and a second reviewed apply was a verified no-op. A fresh
Axe-Edit1.15.02 comparison confirmed the exact two disconnected positions,
Dual Detune, Mix25% and Level0dB. These are insertion defaults, not a claimed
octave setup or audible preset. No Store, globals or reference presets changed.
This evidence applies to the exact fixture, not general chain construction.

The existing octave setup separately accounts for the captured model9
default change at opaque Pitch word35 (1 to2 for a freshly inserted block).
This is a consequence of model selection, not permission to set that field.
An unmeasured starting default refuses before staging. Auto Engage capture
is separate evidence and does not enable it through this placement primitive.

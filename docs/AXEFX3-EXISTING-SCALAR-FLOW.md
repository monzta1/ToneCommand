# Preserving existing-preset scalar execution

This focused experimental port composes #297's unchanged pure contract with
the complete observation, exact official writer and original-scene survey
contributions. It is not registered in the ordinary app. `ExistingEditor` owns
its real survey and connection-bound review; AI/browser-provided observation,
Context, frame, model, ownership or permission fields are never accepted.

The initial candidate control surface is deliberately limited: Amp 1/A with
59 Bassguy Bright (model0), Amp 1/B with Vibrato Lux (model121), and Gain/Mid.
Each value is 0.1..8.0 in tenths, at most one display unit per fresh review.
The existing original scene recalls the channel: no channel assignment, model,
bypass, level, route, controller, cabinet, NAM or Store write is added. Unrelated
instances/modifiers and unknown opaque words remain preserved. A modifier owns
its address even with source NONE. Physical MK1 acceptance remains separate.

The host obtains all eight actual scene maps under explicit target/mute
confirmation. Only sanitized scene/control metadata is given to the selected
provider, never raw system, factory or modifier words. The unchanged pure
compiler checks every scene's real active coverage and all shared-channel
impacts, rejects no-ops or unsupported changes and returns a review-only delta.
Missing musical capability must lead to scope clarification, not invented
parameters, arbitrary insertion or silent omission.

A connection-owned 180-second one-use review is checked against fresh complete
state. Before any scalar, SEND surveys all eight maps again and compares them
with the original survey. Each scalar recalls an original scene using its
channel, rechecks ownership/context, consumes one exact typed output permit,
then compares the entire complete state and independent formatted display.
Only reads settle. After all scalars, another complete eight-scene survey
checks original assignments, and the original scene returns with exactly the
approved words changed. Unknown outcomes stop/latch without SET retry,
automatic Undo, reload, rollback or Store. External mute is not a limiter.

Synthetic, exact-source native and independent Axe-Edit acceptance are reported
separately. This intentionally is not all existing-preset parameters, all amp
models, a full new-build planner or acoustic verification. The broader local
integration is separate evidence, not a substitute for testing this port.
Normal REVIEW/CONFIRM/SEND host integration is the following contribution.
